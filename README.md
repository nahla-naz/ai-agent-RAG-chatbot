
# AI agent RAG chatbot Web app 1.0 (AI assistant)

# Description: 
Chatbot web application which acts as a Customer support AI assistant.

# Tools used:
Langchain
Ollama
Django

# Models used:
LLM model: llama3.2
Embedding model : mxbai-embed-large

# Pre-requisites: Python 3.11

1. Python libraries to download:
    langchain-ollama
    langchain
    langchain-chroma

2. Download Ollama from Ollama.com

3. Download Ollama Models:
    cmd>ollama pull llama3.2
    cmd>ollama pull mxbai-embed-large
